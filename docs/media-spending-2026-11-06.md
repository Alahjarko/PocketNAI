# 动图、消费流水与 Effort 验证（2026-11-06）

本轮在原版0.1.32之上开发，首轮本地验收版本为0.1.32-media/code32；下方性能数字与末尾摘要对应这份本地验收包。本次正式发布使用0.1.33/code33，附件名PocketNAI.apk，见[build-33发布页](https://github.com/Alahjarko/PocketNAI/releases/tag/build-33)。沿用既有签名，覆盖安装MuMu原实例127.0.0.1:5559，未卸载、清数据或操作本机连接的实体手机。

## 范围

- GPT Image 2.6新增GIF实验开关，默认关闭；画廊显示静态首帧及右下角小型GIF标识，详情仅当前可见图播放。GIF被SFW遮挡、滚出可视区域或进入后台时停止；全屏不让下层详情重复播放。
- 封面按目标尺寸解码并缓存，最多两路静态GIF解码；SFW沿用48px专用缓存。Android 9及以上使用ImageDecoder静态位图解码，Android 8使用Movie零时刻绘制。
- SVG支持静态矢量文件保存、显示和导出，拒绝外部资源、脚本与动态内容。向系统导出GIF保留动图，SVG保存到Downloads/PocketNAI；GIF编辑使用首帧PNG。
- 消耗统计提供总览/Anlas/OpenAI，不混加两种单位。OpenAI独立流水在删除图片后保留；有效usage按冻结费率折算，缺失用量和SVG未覆盖的矢量编写费保持待确认。
- 详情显示实际请求开始至本地保存的生成用时，排队不计入；旧记录不猜测耗时。
- Opus开关仅对V5的Normal预设启用28步下限，自定义尺寸和其它档位不受此限制。Effort默认High，V5 Full可选固定14步的Medium；Normal下限启用时阻止冲突组合。协议与价格依据见[Effort核对](novelai-effort-2026-11-06.md)。
