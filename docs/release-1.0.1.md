# PocketNAI 1.0.1 发布核对

2026-11-24 经用户确认后发布 [build-48](https://github.com/Alahjarko/PocketNAI/releases/tag/build-48)。本版针对 1.0.0 平板真机反馈集中修复动效、共享元素过渡、抽卡配置导入导出与对话附件入口：

- **大图模式交互与动效**：支持未放大状态下手指上下滑动切图（实时跟手与边缘阻尼），胶片条点选、滚轮与 `A`/`D` 切图统一使用方向感知上下滑动过渡。
- **看图与共享元素修复**：`DetailImagePane` 与 `HomeWorkbenchPane` 精确按图片实际宽高比约束共享元素容器，消除平板相册进详情返回时的 0 帧放大跳变；详情退场稳定后自动释放旧共享状态，并为首页 `[ 大图预览 | 相册预览 ]` 接入独立共享元素作用域，实现「从哪来就到哪去」过渡。
- **平板导航与面板动效补齐**：移除顶层 Tab 切换时的整页缩放以消除左侧栏 0 帧缩小扩张；首页右侧生成面板展开/收起补齐弹簧过渡；设置页左侧四大类切换补齐方向感知过渡动效。
- **抽卡实验室导入导出与 MD3 重塑**：`ArtistCatalogReader` 支持流式解压导入本应用导出的 ZIP；JSON/ZIP 导出同步保存停用名单、锁定基底画师与阶梯权重，导入弹窗默认同步应用文件中的启用/停用配置；「新建抽卡实验」弹窗重做为居中圆角 MD3 分组卡片样式。
- **对话输入框优化**：移除底部 `+` 下拉菜单与麦克风按钮，改为直观的「相册」与「画廊」双胶囊入口。
