旧批次和收藏保留原始画师串；新建实验使用扩充名单。Danbooru 标签存在不保证所有 NovelAI 模型的识别强度，真实效果需要用户固定参数抽卡对比。

排除记录保存在 JSON 的 `exclusions`。失活、无作品或种子ID身份不符的候选未入池；不能把候选数量当成已审核入池数量。
