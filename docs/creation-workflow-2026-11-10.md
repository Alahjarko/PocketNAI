# 创作流程优化

用户批准上一轮评估的第2～7项，长回复阅读策略保持现状。本轮验收清单：

- [ ] 历史选图：统一大面板，搜索、模型/收藏筛选、大图预览，保留选择和滚动位置。
- [ ] 会话草稿：文字、选区、附件按会话保留；历史支持搜索、重命名与置顶。
- [ ] 绘伴改词：图片详情可带图及参数进入绘伴；可编辑的改词卡，由用户应用/撤销，仅改提示词。
- [ ] 交互细节：思考、高级参数、详情参数展开过渡；收藏等长表单统一开合与固定操作区。
- [ ] 任务概览：真实模型、排队/生成状态和等待时间，可定位对应图片，不虚构进度。
- [ ] 加载：图库按需查询筛选结果，会话列表只读摘要；完整历史、筛选语义、多选与详情顺序保留。
- [ ] 数据与设备：显式迁移、50项以内回归、Instabox构建/覆盖安装/实际界面验收、原签名正式发布。

沿用既有请求、费用、凭据、SFW与内容规则，不自动发起真实生成或聊天。RikkaHub仅作交互参考，独立实现。

## 实现与验证进度

开发分支`feat/creation-workflow`。schema 14→15仅新增会话置顶列、独立草稿表、生成记录的归一化搜索列和图片排序索引，不重建历史表。历史摘要不读取正文；图库默认查询120张，接近底部继续加载，详情顺序和全选单独查询全部匹配ID。超长检索词在后台回退精确匹配，避免SQLite表达式限额。

改词建议是独立的只读工具结果；用户可编辑和选择应用正向/排除词，应用/撤销核对对应服务与草稿内容，不生成图片，不修改模型、尺寸、Seed或参考图。草稿文字/选区/附件按会话持久化，删除或移除附件前核对全部历史和草稿的存活引用。

Instabox已完成源码`59f7e36`的29项JVM测试与Debug/AndroidTest构建；21项设备回归正在核对。后续修正需以最终源码重新验收。现有Android容器曾失去窗口服务，核对`/data`持久卷后原位重启恢复，未创建新设备、未卸载应用或清数据。测试包证书与原沙箱安装一致。

独立离线验收入口`CreationWorkflowPreviewActivity`仅在`galleryBenchmark=true`启用：独立应用ID、无网络权限，使用2000张本地几何图片和2001条会话摘要检查分页、筛选、界面与返回，不进入发布包。
