# 对话多图计划与搜索服务

本轮基于已发布的0.1.31，针对漫画/分镜创作开放明确确认后的多图执行，并接入DeepSeek和Tavily搜索。聊天与搜索提供商相互独立。

## 多图计划

`generate_images` 接受最多12项独立参数，沿用现有单图校验。整个计划先验证，再冻结本地宏与旧随机提示词；每项仍是一次 `sampleCount=1` 的NovelAI请求。没有修改生成接口的多图计费语义。

确认卡展示数量、单项模型/画布/提示词/报价、可展开的完整参数和可确定的Anlas总额。V5额度与未知费用单列，不将额度覆盖推断为整批免费。每条消息合计最多12张；旧自动执行开关兼容为单图自动，多图须确认。

后续按用户要求增加“完全允许”：主动选择并保存后，发送消息即授权本条图片任务及可能费用，包括报价变化或未知，不再弹计划确认。每次确认/单图自动保留原费用复核；完全允许仍有数量上限、账号绑定、权限撤销、停止与失败不重试。默认及旧配置不会升级为完全允许。

确认卡取消240dp内层滚动和重复说明，每张成为带箭头的整行入口，完整参数随时可打开；外层聊天列表统一滚动。筛选弹窗固定宽度，模型与模式独占一行，不再由选中标签改变FlowRow换行与菜单锚点。跟随滚动收到layoutInfo后等待下一帧再使用最新边界，避免参数阅读器往返时重入测量。

`ChatImageBatch` 串行执行，至少间隔1秒，逐张保存结果。每张前检查账号、报价和停止状态，报价变化重新确认剩余计划。由于共享生成锁可能等待，实际HTTP发送前再次检查权限和报价；等待期间发生变化则不发请求，要求重新确认。调用失败、结果不确定或取消后封锁该条消息的剩余生图，不自动重试。

停止按钮对已发送请求只设置停止后续标记，当前图片完成后保存；未发送部分取消。中断恢复保留已经完成的图片，只补工具结果，不恢复发送计划。沿用原图片表、图库、签名和加密凭据，无数据库迁移。

## 搜索

入口：对话菜单 → 连接与人格 → 联网搜索。默认关闭，选择提供商并填写对应API Key；搜索密钥与聊天密钥独立保存、更换地址重新填写。用户打开后，发送消息允许agent按需查询，每条消息最多6个不同检索词。

| 服务 | 默认Base URL | 请求字段 | 提供给LLM |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `query`、`count=5`、`need_content=false` | title、url、summary（回落snippet） |
| Tavily | `https://api.tavily.com` | query、basic、max_results=5；关闭auto_parameters/answer/raw_content/images | title、url、content |

只读检索词最长128个Unicode字符。响应限制512KiB，每次最多5条来源，每条摘要最多2000字符。密钥不进入模型、数据库明文、异常或日志；不自动重试或跟随重定向。网页资料作为tool数据，来源链接可由用户点开，不自动加载外部图片或作为生成参考图。

官方协议核对：[DeepSeek Search & Fetch](https://api-docs.deepseek.com/guides/search/)、[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)。本轮仅实现Search，不调用Fetch；搜索结果不能保证绘图模型认识角色，也不能保证跨图角色完全一致。

## 验证方式

- 扩展既有JVM项目：整个计划校验、独立参数、数量预算、确认/取消、报价变化、发送前复核、不确定失败停批、停止后续、保留已完成图片；两家搜索的HTTP合同、响应清理、无重试/重定向。
- 扩展既有聊天设备项目：真实ChatViewModel、Compose界面、内存Room、独立加密测试配置和本地图片，搜索/LLM/生图均是假实现。确认前0次调用，三图完成共3次调用；第二张模拟断流时第三张不发送；生成中停止后保留当前图。保存和重读时图片索引不重复，来源可保留。
- 原生成链路设备测试先跑，其余设备测试随后运行。注册总量保持29项JVM + 21项设备 = 50项。
- 证据目录 `.tooling/agent-20261105/`：构建/设备测试日志与实际截图。真实搜索账号连通性、搜索质量和真实漫画成图效果未在本轮代用户调用验证，不消耗用户搜索额度或Anlas。
