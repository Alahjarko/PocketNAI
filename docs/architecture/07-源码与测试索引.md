## 3. 测试分层与实际覆盖边界

| 测试组 | 已有内容 | 不应据此推断 |
|---|---|---|
| 纯规则JVM测试 | 模型/参数、提示词、费用、几何、metadata、搜索、日期、更新判定 | 原生输入法、位图编码和真实服务器行为已被验证 |
| MockWebServer契约 | 登录、账户/余额、补全、超分等请求响应 | 本次可用账号、真实订阅或服务端计价永久不变 |
| 数据映射/草稿 | Entity映射、DTO恢复、收藏/流水相关仓库逻辑 | 全部数据库故障和跨进程恢复都已有覆盖 |
| Android图片处理 | OutputImageProcessor裁切与元数据 | 另一平台位图库像素/颜色行为相同 |
| Android迁移 | Room旧库迁移 | 跨平台导入包已经存在 |
| Android生成闭环 | 假API + 内存Room + 文件，Seed与画布对应 | 可以自动用真实Token生成 |
| Android控件 | 分辨率说明与控件行为 | 全应用UI回归全覆盖 |
| SOCKS探针 | 特批真实GET检查代理连通 | 应在普通CI或默认全量测试中联网运行 |

本次只统计和阅读测试源文件，不把源码中的`@Test`数量当作执行通过数量。下方索引包含测试辅助文件，因此“文件数”也不等于“测试类数”。
