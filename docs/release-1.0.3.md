# PocketNAI 1.0.3 发布核对

2026-11-25 经用户确认后发布 [build-53](https://github.com/Alahjarko/PocketNAI/releases/tag/build-53)。本版修复抽卡实验室大图检视模式下收藏触发置顶重排导致的浏览进度回跳问题：

- **抽卡大图检视冻结浏览顺序**：进入抽卡「大图检视」时冻结本次浏览顺序快照，检视期间点击收藏/取消收藏（或按 `F`）实时更新收藏状态，不再因置顶重排将当前进度拉回第 1 张，按下一张继续顺滑浏览后续卡片；在「仅收藏」中误点取消收藏也不会立刻跳走；退出大图回到网格后，新收藏的卡片仍自动置顶便于集中查看。
- **动态兼容实时出图与筛选切换**：若实验仍在后台跑图，新完成的卡片顺延追加到冻结序列末尾；主动切换左侧栏「全部 / 仅收藏」筛选芯片时，自动按新筛选刷新检视序列。
