# 颜色过渡、预测性返回与画廊参考来源

本轮只改善颜色模式、返回手势和参考图来源导航，不改变生成参数、服务商或内容开关默认值。

## 颜色

全部颜色角色使用同一个280ms可中断时钟；首次进入直接使用目标主题，连续切换从当前显示颜色继续，沿用动态取色。权重底纹同步过渡；模式按钮圆角、选中色和图标宽度有短动画，整块保持至少48dp点击范围与单选语义。中间色的文字对比度不足时，使用适合当前底色的端点或黑/白前景；系统栏图标随实际背景明度更新。Compose动画遵循系统动画时长设置。

## 返回

- 详情移除普通BackHandler拦截，由现有Navigation Compose驱动手势进度和取消。Pager提前准备当前图的返回目标；工具栏返回仍锁定当前图。
- 面板使用PredictiveBackHandler：手势期间只改变绘制位置，提交后收起，取消恢复展开；不重建表单或滚动容器。把手拖动阈值和内容区不拖动面板的规则保持。
- 蒙版页和统计二级页使用同类可拖回过渡，底部Tab仍短淡入淡出。系统弹窗、全屏图片窗口沿用系统关闭处理。
- 来源图详情使用独立导航条目和图片状态，结果图→来源图→更早来源图可逐层返回，不覆盖原画廊/聊天的图片返回目标。

依据：[Android预测性返回](https://developer.android.com/develop/ui/compose/system/predictive-back)。手势提交/取消和系统窗口动画不能由Layoutlib代验。

## 来源

新选的本机画廊图片按原始路径保留图片ID，归一化、补边不改变来源身份。图生图、Precise、Vibe、暂未启用的保留参考图和OpenAI参考区均显示来源小图；结果详情另有“来源参考图”。点击进入原图详情，返回保留此前页面与草稿。来源删除/撤销由数据库Flow更新；删除后显示“来源图片已移除，参考图仍可使用”。新缩略图遵循既有SFW显示规则。

sourceImageId只用于本机导航，不进入生成请求、PNG或共享文件。草稿和历史均保留。相册与无法验证来源的旧参考保持null，不按重新编码后的哈希猜测。Room12→13仅给reference_images加可空列，不重建generations，不建立向原图级联删除的关系。

## 验证

扩展既有草稿往返、参考图导入/存储、迁移和图片返回项目，不新增@Test方法，预算仍为29项JVM加21项设备测试。设备测试仅编译。原生预览使用生产插值及来源入口，覆盖浅/深色、大字体、来源存在/移除，另检查61个过渡位置的基本文字对比度。

本机SQLite按Room12导出结构执行原样迁移SQL，旧历史/图片/收藏/对话保留，旧来源为null，删除原图后参考副本记录仍在；这不替代Android端Room迁移执行。全程不用安卓模拟器，不发真实AI请求。最终云端运行与APK摘要记入发布文档；真机触控、缓存切换和手势仍待验收。
