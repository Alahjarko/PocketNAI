# PocketNAI 0.1.34

## 账号操作更安全

- 断开 NovelAI 连接前增加二次确认，明确说明移除范围及保留的数据。
- 账号移除、提供商删除，以及 OpenAI 生图／联网搜索密钥移除均需确认；取消不删除凭据。
- 确认期间目标账号或密钥发生变化时，拒绝误删新的配置。

## 多提供商与模型切换

- 「连接与人格」移至设置中的独立二级页面，不再放在对话菜单内；无需开启对话即可预先配置。
- 支持保存多个 OpenAI-compatible 提供商，每个提供商独立保存地址、加密密钥和多个模型。
- 支持手动添加模型或主动获取模型列表；各模型分别保存思考协议、思考开关及输出上限。
- 对话顶部新增按提供商分组、可搜索的模型选择器，切换时无需删除或重新输入旧 Key。
- 人格、工具权限和联网搜索统一从设置管理；切换提供商不重置人格及工具权限。
- 已有单连接配置自动迁移。凭据绑定提供商及地址，改变地址时须提供新密钥，避免把旧密钥发送到其他服务。

## 数据与兼容性

- 删除当前使用的提供商／模型会清空选择，不会自动切换到其他服务；聊天和图片历史不删除。
- 聊天执行期间禁止变更连接，避免正在执行的请求使用错误配置。
- 本版本继续使用 OpenAI-compatible 聊天接口，不新增 Claude／Gemini 原生协议。
- 本地编译优化 Release，经 GitHub Actions 使用原项目密钥签名；保留已有正式版的升级签名兼容性。

验证：29 项 JVM 测试及 21 项 Android 设备回归通过；测试使用假接口，无真实聊天、搜索或生图请求。
