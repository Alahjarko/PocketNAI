# PocketNAI 0.1.44 发布核对

2026-11-16 经用户确认后发布 [build-44](https://github.com/Alahjarko/PocketNAI/releases/tag/build-44)。本版全面打磨前端视觉色阶、画廊多选与长按操作面板、SFW 遮罩点开触感与揭开淡入，并消除多处局部瞬切：

- **创作抽屉滚动顶界与收起态留白**：`GenerationSheetScaffold` 按实测把手与头部真实高度计算收起态偏移，保证生成按钮下方呼吸间距充足且收起态严格隐藏表单；将顶部内边距移入滚动区并配合分割线透明度过渡，消除向下滚动时控件在分割线下方 `16dp` 空白带被生硬截断的现象；负向词折叠、高级参数与详情参数箭头接入图层弹簧旋转。
- **设置主页与消耗统计色阶统一**：主设置页与统计页全部区块统一升级为 `24dp SettingsCard`（`surfaceContainerLow`），恢复 `40dp` 圆形图标底托对比度，并为生图服务、颜色模式、SFW 开关及统计趋势柱形补齐按压弹性与轻触感。
- **画廊长按动作面板与多选微交互**：长按图片升级为带圆角缩略图、模型尺寸摘要、顶排快捷胶囊（收藏 / 保存相册 / 分享）与危险色独立删除项的底部动作面板；多选顶栏等高丝滑切换避免瀑布流跳动，底部操作胶囊弹簧进出，选中卡片支持 `0.945x` 弹簧内缩（仅多选态挂载，日常滚动零额外开销），收藏角标在多选换位时柔和淡入。
- **SFW 遮罩点开触感与零空白帧揭开**：SFW 模式下点开受遮罩缩略图补充 `CLOCK_TICK` 轻触反馈；详情页点击 `SFW · 点击图片查看` 揭开时触发 `CONFIRM` 确认振感，并由 `SfwRevealImage` 让原图在模糊图上方约 `220ms` 平滑淡入（解码期间模糊图垫底、全程零空白帧，重新遮罩时单帧即刻撤除原图不留残影）。
- **全屏看图器离场与局部提示有界展开**：补齐全屏看图器入场与下拉/单击关闭的短弹簧收尾过渡，优化主页面切换 Fade-Through 曲线；历史选图对勾统一弹出动效，导入进度条、尺寸/校验错误、服务切换提示及对话改词卡「已应用」行统一改用 `AnimatedDisclosure` / `AnimatedNote` 有界展开，不再单帧推挤下方控件。
