# 0.1.31 / build-31

2026-11-04 本机正式R8构建，沿用既有签名，版本号31。

## 变更

- 多图SFW画廊缓存保护：从原预算中按需划分最多2MiB保留模糊小图，减少往返滚动时重新解码、模糊；未使用SFW时不缩减普通图预算。
- 历史缩略图不再在加载成功时触发无用的整卡重组；历史揭图动画与等待动画减少重组和临时分配。
- 额度波形滚出屏幕后停止动画时钟，回到可见区域恢复。
- 画廊新增返回顶部按钮，长列表回顶动画距离有界。
- 停用公共代理和流式预览，保留自定义HTTP/SOCKS5。
- 增加独立、离线的150张格子图性能夹具，测试源码不进入生产APK。

## 验证

- JVM 29项、设备21项，注册预算50；原有画廊测试扩展缓存压力与清理检查。
- 150张图包含100张敏感标签、50张普通标签；两次最终SFW热轮均无重复模糊、无图片加载错误。此前同APK缓存对照热轮重复模糊42次。
- 同APK缓存对照分配34,062,384→31,514,672字节；最终加上卡片重组优化后两次为29,999,152/30,130,224字节。缓存总预算不变。
- 屏外波形静置12秒，绘制帧数2185→0，CPU 1.89秒→低于采样精度。
- 模拟器尾帧仍存在波动；不宣称全场景零掉帧或真机120Hz已全面达标。详见[多图SFW报告](sfw-gallery-performance-2026-11-04.md)与[前一轮性能记录](performance-2026-11-04.md)。
- APK包名 `net.pocketnai`，versionCode31 / versionName0.1.31，生产DEX不含GalleryBenchmarkActivity。
