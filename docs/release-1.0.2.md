# PocketNAI 1.0.2 发布核对

2026-11-24 经用户实测确认后发布 [build-52](https://github.com/Alahjarko/PocketNAI/releases/tag/build-52)。本版聚焦打磨平板工作台动效、实体键鼠交互、大图生成反馈与多任务体验：

- **面板展开/收起连续弹簧与双层画廊溶解**：右侧生成面板、顶栏按钮、大图舞台、胶片条与底栏共用同一条可打断弹簧，1:1 同像素咬合滑动；相册瀑布流采用宽/窄双固定列沿面板边缘连续裁剪与交叉溶解，消除卡片乱飞乱排与闪烁，并保持滚动锚点与 SFW 模糊缓存稳定。
- **大图模式流畅切图与生成过渡**：底层切换为原生 `VerticalPager`，消除手指上下滑切图回弹抖动；新图生成到达或从占位卡出图时平滑滑入/缩放入场，不再 0 帧硬切；底部工具栏瘦身为单行清爽布局。
- **实体鼠标深度优化**：舞台在 `Initial` 阶段接管纵向滚轮，支持细分刻度累积与单通道连续翻页（`Ctrl + 滚轮` 围绕光标缩放、放大后滚轮边界内平移、移至胶片条原生滚动）；未放大时支持左键直接拖动大图到右侧参考图区，并补齐拖拽缩略图阴影预览。
- **筛选切换与共享元素零闪烁**：切换「同步筛选 / 全部图库」原子提交数据并按当前图片 ID 对齐（跨窗口自动扩窗），不再闪现空态；修复相册进详情正向无过渡、搜索栏覆盖层卡顿、详情翻页立刻返回共享元素错位及 GIF 起播闪烁。
- **胶片条多任务占位与极简展示**：每个活跃生成/排队任务的未产出槽位独立展示在胶片条中（生成中优先、排队顺延，互不覆盖），在大图模式直接点生成时顶部自动露出且不受历史筛选隐藏；胶片条精简为居中 36dp 纯动效，去除拥挤文字。
