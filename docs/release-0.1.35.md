# PocketNAI 0.1.35

设置中的「连接与人格」入口及内部配置页面采用统一的图标、分组、文字层级和按压反馈，改善0.1.34新增提供商设置与其他界面风格不一致的问题。

- 连接页加入可折叠大标题、当前模型摘要、提供商状态与操作菜单。
- 提供商、模型、人格、搜索与Markdown编辑统一使用带开合动画的编辑面板；标题和底部操作固定，键盘弹出时仍可确认或保存。
- 页面进入、返回和逐层关闭衔接；模型列表按需加载，列表增删保留位置动画。
- 保留已有账号、加密密钥、权限、删除确认和请求规则。

设计对照、实现范围与实际操作记录见[本轮记录](provider-settings-polish-2026-11-10.md)。
