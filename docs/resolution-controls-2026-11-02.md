# Wallpaper 与 OpenAI 自定义尺寸

## NovelAI

新增 Wallpaper 档位，竖图1088×1920、横图1920×1088，无方图。切档保留横竖方向；原为方图时回落竖图，方图按钮禁用。尺寸直接作为生成画布发送，不使用精确自定义尺寸的裁切。草稿和历史仍保存宽高；归属档位通过宽高反查，不增加数据库字段或改变旧历史。

来源：2026-11-02匿名读取[官方生图页](https://novelai.net/image)及其公开脚本`/_next/static/chunks/22evx8_5gmu-c.js`。脚本中的预设为：

```text
{name:"Portrait",width:1088,height:1920,category:"Wallpaper"}
{name:"Landscape",width:1920,height:1088,category:"Wallpaper"}
```

当次脚本SHA-256：`81878eb2b901067f47ec5541c24974267dd7676833cb33c555a551bc331bdf88`。公开前端脚本可能更新，不是服务端永久兼容保证。没有登录或发送生成请求。既有Normal/Large尺寸未在本轮调整。

窄屏或大字号时，方向按钮作为一组换行，避免长档位名被拆断或按钮被挤出。

## OpenAI

增加3840×2160、2160×3840预设。自定义使用两条独立滑条，16px步长、480～3840范围，并保留数字输入与交换宽高。480为符合既有最小总像素和最大宽高比要求的最小可用对齐边长；每边可到3840，但不能同时将两边拉到3840。

保持原有服务约束：宽高16对齐、每边≤3840、比例1:3～3:1、总像素655360～8294400。编辑时允许暂时超限，另一边不被静默改写；就地显示具体原因，生成按钮和发送前校验阻止非法请求。`auto`继续按原字符串提交。高分辨率沿用实验性提示和生成前额度确认。

尺寸仍保存在`OpenAiImageParams.size`，请求、草稿持久化、历史详情及复用共用同一个值。没有改变模型、质量、API字段或输出后处理。
