# OpenAI 实验性生图

本文件是[开发约定](../../AGENTS.md)的专题补充。涉及生成时，同时阅读图片、网络、存储、界面及验证专题。

## 入口与范围

设置 → 生图服务切换 NovelAI / OpenAI。OpenAI 使用用户自己的 Platform 密钥与额度，提供 GPT Image 2.6 与 2.5 的 Flare、Sunburst（完整ID见[2.6接入记录](../openai-image-26-2026-11-05.md)）。两种服务各自保留草稿；OpenAI 历史支持复用参数，或通过“继续编辑”把成图作为参考。增加模型不改写用户已选模型和旧草稿。

覆盖画廊生图和参考图编辑；2.6增加GIF动图与静态SVG输出。对话图片工具和画师抽卡仍为 NovelAI 专用；OpenAI 模式隐藏抽卡入口，并阻止对话工具误走 NovelAI。设置页在图片任务执行期间禁止切换服务。

## 参数与请求

- 固定连接 `https://api.openai.com/v1`，不套用NAI公共代理。不记录Authorization、描述或原始服务端错误。
- 无参考图时只发一次 `POST /images/generations`；有参考图时只发一次 `POST /images/edits`，JSON 的 `images[].image_url` 使用PNG data URI。
- 描述原样发送，不经过NAI质量词、权重、宏、负向预设或漫画文字处理。不发送NAI的Seed、采样器、步数、角色或 `input_fidelity`。
- 2.6 的 `complexity` 为 low/medium/high，默认high，仅2.6发送；草稿、历史、复用、确认和详情共同保留。2.5请求省略此字段。2.5支持PNG/JPEG/WebP；2.6另支持GIF与SVG，markup未接入。格式切换必须经过本地模型能力校验，不能给2.5发送GIF/SVG。
- 静态位图张数1～10；质量 `low / medium / high / xhigh / max / auto`；压缩仅用于JPEG/WebP；背景 `auto / opaque / transparent`（透明禁止JPEG）；审核 `auto / low`。GIF与SVG每次限一份输出。
- 尺寸支持 `auto`、预设与自定义。宽高为16的倍数，每边≤3840，比例1:3～3:1，总像素655360～8294400。超过2560×1440的像素量标明实验性。
- 尺寸菜单包含3840×2160及2160×3840；自定义用独立宽/高滑条（480～3840，16px步长）、数字输入和交换宽高。拖动一边不暗改另一边，允许暂时输入超出总像素/比例的组合，但就地提示并禁用生成；界面、仓库与HTTP发送共用`OpenAiImageParams.sizeError`校验，参数仍按原`size`字符串持久化和复用。说明与验证见[尺寸控件记录](../resolution-controls-2026-11-02.md)。
- 最多16张参考图；本机单张PNG≤14 MiB、合计≤24 MiB。响应从流中解码，读取上限64 MiB，避免复制整份base64响应造成内存尖峰。
- 2026-11-05重新核对标准费率仍为文本输入$5、图片输入$8、图片输出$30/百万token。2.6低/中质量输出token分别在2.5计算结果上乘4.2/3.3后四舍五入，高/xhigh/max不变；不能直接复用2.5低/中质量报价。历史已冻结费率保留，证据见[2.6接入记录](../openai-image-26-2026-11-05.md)。
- 禁止自动重试、重定向及断流降级重发。超时、5xx或已收到结果但保存失败，标记结果/计费待确认；已保存的部分结果保留，不补发缺失图片。
- 生成前确认模型、尺寸、质量和张数，并显示粗估总价：静态位图输出采用官方 GPT Image 2.5 计算器并应用上述2.6系数，文本按 UTF-8 字节数÷3 粗估，每张参考图按每张成图 $0.05 本机预留（非官方按张定价）。auto质量显示low～max区间，auto尺寸不报价。完成后按有效整次usage和冻结费率折算，不再乘张数：文本输入每百万token $5、图片输入$8、图片输出$30（2026-11-02核对）。直接Images API不使用缓存/Batch折扣；无完整有效用量保持未知，不当成免费。本机预算不是账单或误差保证，见[费用粗估规则](../openai-pricing-2026-11-02.md)。

## GIF与SVG（2026-11-06）

- GIF在设置 → 生图服务 → OpenAI中由“GIF 制作（实验）”开关启用，默认关闭并持久化。关闭时隐藏格式选项，仓库也会拦截恢复草稿或复用历史中的GIF请求；不能只依赖界面隐藏。
- GIF仅支持2.6，每次一张动图，使用 `size=auto`，不开放自定义帧尺寸。`frame_count` 为2～16，默认9；`frame_duration_ms` 本机范围20～2000、10毫秒一档，默认200。界面提供20/50/100/200/500/1000/2000毫秒，草稿、冻结请求、历史与详情保留这些字段；非GIF请求省略动画字段。上述时长范围是本机实验功能的边界，不代表服务端所有能力。
- SVG仅支持2.6的单张文生图，不支持参考图编辑。保留原始SVG字节，以静态矢量方式显示和导出；不接入WebView、脚本或外部资源。校验拒绝DOCTYPE/ENTITY、处理指令、事件属性、外部链接、动画及非允许元素；本地片段引用允许。SVG最多8 MiB、50000元素、128层嵌套，画布仍限制每边3840及总像素8294400。返回格式与请求不符、解析失败或超过边界，按“已返回但无法保存、可能已计费”处理，不重发。
- GIF和SVG不套静态位图的生成前报价公式，粗估保持未知。GIF有完整有效usage时可按本次冻结费率折算整次金额，不额外乘帧数。SVG还涉及矢量编写费用，当前快照没有足够信息覆盖整笔费用，即使有图片usage也将总金额保持未知；用量仍可查看，以服务商账单为准。

## 媒体显示、导出与性能

- 原始PNG/JPEG/WebP/GIF/SVG字节保存在现有历史目录，按实际格式保留扩展名和MIME；导出、分享不将GIF拍平成PNG或将SVG伪装成位图。GIF复制到系统相册，SVG保存到下载目录的PocketNAI文件夹。
- 画廊、转场及默认缩略图使用GIF静态首帧。详情和全屏仅在当前可见页面、应用处于前台且未被SFW遮罩时播放；离页或后台停止播放。静态首帧与播放请求使用独立缓存标识，避免动图占满画廊解码预算或误复用播放缓存。
- SFW继续复用低分辨率静态模糊和缓存，不对每一动画帧重新模糊。SVG按显示区域栅格化预览；原始矢量文件不因此改变。媒体解析与文件保存运行在后台，统计快照解码及金额聚合也运行在后台，不随每帧重算。
- GIF详情的继续编辑入口明确为“编辑首帧”；SVG不提供位图继续编辑入口。OpenAI详情不显示无意义的Seed或NAI超分按钮。实验功能的真实媒体显示仍须设备验收，不能以解码测试或源码推断代替截图和播放检查。

## 存储与并发

- `OpenAiImageSettings` 使用 `pocketnai_openai_images`；密钥用既有 `SecretBox` 和独立Keystore alias加密，不预填或复制，云备份与设备迁移均排除。
- `OpenAiImageViewModel`由`AppContainer`持有，同一服务的手动提交允许并行，仓库最多三项同时处理；每项先写独立生成占位，再等待并发位，生成键和下一份草稿保持可编辑。共享服务占用标记直到最后一项结束才释放，期间仍禁止切换服务/密钥，与NAI和抽卡保持互斥。导航和Activity重建不重发POST；启动恢复每进程一次，新任务等待首次恢复结束。详见[调度记录](../generation-queue-2026-11-02.md)。
- 数据库v12只给 `generations` 添加可空 `openAiParamsJson`，保留既有表和外键。历史存实际OpenAI模型ID与独立快照；兼容旧画廊的旧列不能据此构造NAI请求。
- 响应usage、返回张数和提交时费率/粗估使用同一JSON快照。更新必须用`updateOpenAiSnapshot`，不能重复调用IGNORE插入来更新，也不能REPLACE父记录；部分图片保存失败仍保留整次usage。新JSON字段可缺省，旧记录不会伪造用量。
- v14新增独立 `openai_spending` 流水表，一次请求一行，不以图片数量、帧数重复计费；插入生成占位及更新状态/快照时用触发器同步，保留部分成功及待确认状态。表不依赖图片外键，因此删除图片或清理历史不删除流水。迁移只回填仍在本机的旧快照；启动不重复回填，用户清空流水后不会重新出现。此前已删除的历史无法恢复，密钥不进入快照。
- 设置入口为“消耗统计”，总览、Anlas、OpenAI分别显示；Anlas观察扣减与美元用量折算不能混合相加。OpenAI按冻结费率统计已知usage，生成前粗估和未知金额单独显示、不计入已知合计。每个服务可单独清空流水，不改变图片或服务端账单；详见[计费专题](billing.md)。
- v14给生成历史增加可空 `generationDurationMillis`。NovelAI/OpenAI从实际请求开始到本地保存/收尾记录单调时钟耗时，排队等待不计入；这是整次请求耗时，不能称为模型纯推理时间。详情的完整参数显示“生成用时”，旧记录或尚未发送的任务显示未记录，不以创建/更新时间反推。失败或取消后的已发送任务也尽可能保存耗时。
- 启动孤儿清理同时保护两种服务的草稿参考图。密钥不得进入数据库、图片、日志、测试夹具或源码。
