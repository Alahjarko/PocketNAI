# 抽卡实验室（实验）

本文件是 [根开发约定](../../AGENTS.md) 的专题补充，入口在设置，默认关闭。

## 功能与参数

- 开启后导航栏出现“抽卡”。新建实验复制首页模型、画布/输出尺寸、步数、Guidance、采样器、调度、质量标签、负面档位。单张文生图，不带参考图、独立角色，不覆盖首页草稿。
- 用户填写固定正负提示词，不含 `artist:`。每张抽 1～10 位不同画师，权重范围 0.5～1.5，步长 0.05，范围上下限含端点、可锁定同档。整数 ticks 10～30 避免浮点误差。
- 自动拼接的画师段统一使用 `1.20::artist: salmon88, ::`：闭合符号前加逗号与空格，避免名字末尾数字被当作新权重。旧批次按原画师和 ticks 还原后使用此格式；旧画师串收藏在展示/复制时修正，保留原数据库主键、图片和已生成的历史参数。
- 表单草稿单独保存在 `pocketnai_artist_lab_draft`，不覆盖首页草稿；重新打开保留提示词、Seed、次数与权重范围。图片结果用懒加载网格，仅绘制可见卡片，收藏排在最前。
- 页面标题下只显示画师数量；按用户2026-10-07要求，不放筛选说明或说明按钮。来源与审核记录留在开发文档和资源清单。
- 标题栏“画师库”展示本地内置的250px代表作，可搜索画师、切换代表作、打开原作链接，以及“移出抽卡”/“重新启用”。本机排除名单保存在独立 `pocketnai_artist_lab_catalog` 首选项，升级后保留；只影响新实验，不重抽已规划批次，不删除图片或收藏。确认新实验时冻结当前启用池，数量不足时在确认前提示。首页人数显示当前可抽取数量。
- 画师库提供“导出”：TXT仅含已启用标签；JSON保存完整名单、代表作来源和排除状态；ZIP在配置和名单外包含本地缩略图。通过系统 `CreateDocument` 保存，不申请额外存储权限，不包含账号、凭据、生成提示词或历史图片。
- 次数 1～10000，默认100；Seed 0～4294967295，按钮随机一次，此后整批固定。所有串开始前一次抽好，逐项落库；逐张不会重新展开基础模板或重抽组合。
- 用户核对参数、数量和整批费用后，确认明确次数的请求。每张只发一次单张请求，前一张完成后随机等待 1000～2000ms；恢复队列第一张也等一秒。没有并行、重试、流式降级补发。
- 切到后台、锁屏或窗口失去焦点不暂停已确认的批次。运行期间使用 `dataSync` 前台服务和有期限的部分唤醒锁，通知栏显示进度并提供暂停。手动暂停/关闭功能/切号/费用分类或金额变化/失败会暂停下一张；继续需重新确认，仅执行 PLANNED，FAILED/UNCERTAIN 不重试。
- `AppContainer` 持有唯一进程级生成与抽卡实例，服务先确认 `startForeground` 就绪才发第一张。服务 `START_NOT_STICKY`、不随 Activity/任务栈退出停止，也不在系统重启或进程重启后自动恢复。服务被停止或 Android 15 的后台时限到达时暂停后续请求并释放资源；已发送请求不重试，进程中断仍按 RUNNING 恢复为既有结果或 UNCERTAIN。Android 15 对后台 `dataSync` 服务有累计时限，见[官方说明](https://developer.android.com/develop/background-work/services/fgs/timeout)。
- 星标同时收藏图片和完整画师串。图片置顶、可只看收藏。取消图片星标不删画师串。画师串收藏以大图网格展示，按画师名搜索；同一串跨批次的结果归到一起，图片星标优先、其余按新到旧作为封面。点卡片看大图、切换多张结果、查看完整权重或进入图片详情，复制与移除入口常驻卡片。
- 收藏预览只关联抽卡记录中同一串的真实本地图片，不用代表作或普通画廊图补位。旧权重文本与安全格式按 `ArtistMix.promptForReuse` 匹配，重复收藏合并显示，删除时使用全部原主键；图片删掉仍保留收藏与复制，显示“暂无关联图片”。使用现有 draw/image 引用，无数据库迁移；移除画师串不删除图片或图片星标。图片关联解码有独立有界缓存，投影运行在后台线程，网格和预览缩略图懒加载。
- 清理仅限当前批次未收藏图片，确认框显示数量。保留收藏、画师串、其它批次、普通画廊。收藏检查与删行同一事务。图片外键 SET NULL；抽卡计划与成功计数保留，清掉的卡片隐藏。

## 数据与复现入口

- [用户精选名单（2026-10-08）](../artist-lab/用户精选画师名单-20261008.txt)：用户保留的160位画师，原文件与顺序完整存档，供后续调整词库参考。
- `app/src/main/assets/artist-lab/artists.txt`：当前174位经过审核的现代活跃画师，本轮实看24位候选、加入17位，侧重厚涂塑形、柔和色彩、皮肤与衣料质感。可编辑审核入口见[现代画师词库审核](../现代画师词库审核.md)；`curated-artists.json` 保存身份、规范标签/别名、活动证据和实看代表作链接。
- 入池须有唯一对应的 Danbooru 类别1规范标签、快照作品数至少50、审核前一年内公开作品或作者官方更新、现代画风实看记录，拒绝AI生成样本。按用户2026-10-07本轮要求，成人向创作不作为淘汰条件；旧 `sfw_review` 保留为历史证据，不参与成人内容准入限制。新增 `work_review` 和可选 `latest_activity_date`，兼容原清单；毛玉牛乳的近期活动以同一作者ID的官方FANBOX发布日期核对。
- `source.json` 保存 2026-10-06 固定快照、修订、数量、源文件/审核清单/词库摘要。Danbooru直连API返回403，明确使用派生统计快照，不称作实时读数。`NOTICE.md` / `LICENSE-2.0.txt` 保留来源和许可。
- `previews.json` 将每位画师关联到小尺寸缩略图和原作链接，摘要记录在 `source.json`。脚本 `scripts/build-artist-previews.py` 只读公开元数据，核对作者ID和AI标记后下载250px预览。作品版权属于原作者，统计数据许可不覆盖图片。界面使用懒加载网格和Coil缓存，图片无需联网加载。
- `scripts/build-artist-pool.py` 只提取标签元数据，不下载作品。词库内置 APK、加载验证数量/去重/摘要。真实标签不代表 NovelAI 所有模型都能准确识别。
- 数量由 `source.json` 决定。运行时最少10位以兼容最大抽样数；内置精选池的重建和资源回归检查要求至少100位，并确保 Mika Pikazo、Modare、Torino Aqua 保留。新建实验用新词库；旧批次的逐项计划、摘要与收藏保留，不重抽或改写，继续既有待执行项仍需用户确认。
- 纯逻辑 `domain/artistlab/ArtistLab.kt`；数据 `data/artistlab/ArtistLabStore.kt`、`data/local/ArtistLabEntities.kt`；页面/队列 `ui/artistlab/`。
- Room v10 只增加 runs/draws/mix_favorites 三表，9→10 显式迁移。每条画师串独立存储，不把万条内容塞入一个大 JSON 行。
- 共用根 GenerateViewModel 生成锁、仓库和记账；请求间隙也预留锁，首页/对话不能插入请求。费用按 N 次单张预估，不能按一次 n_samples=N 计算；每张与发 POST 前检查，V5 额度耗尽造成分类变化暂停。
- 确认账号 fingerprint 对照实际加载 token 摘要，避免切号竞态，不保存 token。RUNNING 的 generationId 发送前持久化；中断只关联已有最终图，没有结果则 UNCERTAIN，不自动继续。
