# 抽卡实验室（实验）

本文件是 [根开发约定](../../AGENTS.md) 的专题补充，入口在设置，默认关闭。

## 功能与参数

- 开启后导航栏出现“抽卡”。新建实验复制首页模型、画布/输出尺寸、步数、Guidance、采样器、调度、质量标签、负面档位。单张文生图，不带参考图、独立角色，不覆盖首页草稿。
- 用户填写固定正负提示词，不含 `artist:`。每张抽 1～10 位不同画师，权重范围 0.5～1.5，步长 0.05，范围上下限含端点、可锁定同档。整数 ticks 10～30 避免浮点误差。
- 表单草稿单独保存在 `pocketnai_artist_lab_draft`，不覆盖首页草稿；重新打开保留提示词、Seed、次数与权重范围。图片结果用懒加载网格，仅绘制可见卡片，收藏排在最前。
- 次数 1～10000，默认100；Seed 0～4294967295，按钮随机一次，此后整批固定。所有串开始前一次抽好，逐项落库；逐张不会重新展开基础模板或重抽组合。
- 用户核对参数、数量和整批费用后，确认明确次数的请求。每张只发一次单张请求，前一张完成后随机等待 1000～2000ms；恢复队列第一张也等一秒。没有并行、重试、流式降级补发。
- 暂停等当前张完成。后台/关闭功能/切号/费用分类或金额变化/失败会暂停下一张；继续需重新确认，仅执行 PLANNED，FAILED/UNCERTAIN 不重试。
- 星标同时收藏图片和完整画师串。图片置顶、可只看收藏。取消图片星标不删画师串，可在独立列表复制、移除。
- 清理仅限当前批次未收藏图片，确认框显示数量。保留收藏、画师串、其它批次、普通画廊。收藏检查与删行同一事务。图片外键 SET NULL；抽卡计划与成功计数保留，清掉的卡片隐藏。

## 数据与复现入口

- `app/src/main/assets/artist-lab/artists.txt`：1000个去重标签。`source.json` 保存 2026-10-06 快照、固定修订、源文件与词库摘要。`NOTICE.md` / `LICENSE-2.0.txt` 保留来源和许可。
- `scripts/build-artist-pool.py` 只提取标签元数据，不下载作品。词库内置 APK、加载验证数量/去重/摘要。真实标签不代表 NovelAI 所有模型都能准确识别。
- 纯逻辑 `domain/artistlab/ArtistLab.kt`；数据 `data/artistlab/ArtistLabStore.kt`、`data/local/ArtistLabEntities.kt`；页面/队列 `ui/artistlab/`。
- Room v10 只增加 runs/draws/mix_favorites 三表，9→10 显式迁移。每条画师串独立存储，不把万条内容塞入一个大 JSON 行。
- 共用根 GenerateViewModel 生成锁、仓库和记账；请求间隙也预留锁，首页/对话不能插入请求。费用按 N 次单张预估，不能按一次 n_samples=N 计算；每张与发 POST 前检查，V5 额度耗尽造成分类变化暂停。
- 确认账号 fingerprint 对照实际加载 token 摘要，避免切号竞态，不保存 token。RUNNING 的 generationId 发送前持久化；中断只关联已有最终图，没有结果则 UNCERTAIN，不自动继续。

## 验证

真实抽卡由用户手动确认批次。助手自动化仅用假 API / 内存 Room，即使报价免费也不能代用户启动批次。
JVM 验证权重网格、单张无重复抽样、万条计划、固定参数、100次串行/间隔、暂停和零重试；设备先跑 `GenerationSeedAndPayloadTest`（百张离线请求、范围清理、收藏保全、中断恢复、发送前同步检查），再跑 `MigrationTest`（9→10历史保全与 SET NULL）和 `ArtistLabQueueStateTest`（暂停/继续、首页锁、参数不污染、断流停止、费用变化暂停）。

2026-10-07 本地验收：634项 JVM 单测通过，生成链路7项、迁移6项、队列状态3项设备检查通过。`ArtistLabLayoutFixtureTest` 通过显式参数临时加入100张带 LAYOUT SAMPLE 标记的本地布局图，实际界面清理保留2张收藏及其画师串；样本随后按固定测试ID清理，不调用NovelAI，不将此结果表述为真实画师出图验证。
