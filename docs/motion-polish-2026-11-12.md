# 首次引导与操作动效打磨

本轮落实已确认的第一批五项：首次欢迎页、统一按压、局部操作反馈、参考图过渡和成图交接。按用户最新要求，完成保存、提交与云端验收后先报告，**不发布 APK**；没有创建新 Release、标签或运行 GitHub 签名流程。

## 改动

- 首次安装显示四角画框展开的原创欢迎页，约 720 ms 完成一次入场。按钮从第一帧即可使用；选择 NovelAI 进入连接页，选择 OpenAI 直接打开生图服务配置，也可“先看看”。连接与跳过固定在底部，介绍区域在矮屏和大字号下可滚动。完成选择后不再显示；已有偏好、升级安装与分享入口跳过引导，不清理任何数据。
- 生成、连接、详情与参考图操作共用轻微按压回弹，Material 原有涟漪、点击语义和触控尺寸保留。设置行沿用较轻的压缩幅度，使用相同响应曲线；动画数值只在绘制图层读取，不逐帧缩小真实布局或延后点击。
- 收藏图标与清空/撤销图标作短过渡；复制完成后原位显示“已复制”，再次点击重新计时。保存按钮显示真实保存中/成功状态，同一张图正在保存时不能重复提交；完成结果只更新对应当前图片，避免滑到另一张后串提示。SVG 保留“下载目录”目的地。
- NovelAI 参考页签下划线随选择移动，面板淡入并过渡高度；新增参考图展开，移除后收拢，退出中的控件不再可操作。页签仍只决定查看哪一栏，不改变素材启用或互斥规则。OpenAI 横向参考图和来源卡使用同样的增删/让位反馈。
- 最终图片解码成功后，图片与完成提示并行过渡，约 240 ms 收尾；移除原先在揭图前串行等待的 230 ms。仍然只有解码成功才揭图，失败和结果不确定不显示成功；旧图片不重播，不根据耗时编造进度。

没有修改生成参数、请求次数、SFW 开关、费用、凭据、数据库 schema 或后台任务生命周期。RikkaHub 仅参考其一致的按压和状态过渡思路，没有复制其欢迎图形或等待动画。
